# Arizon - E-commerce Frontend Application

A fully functional and responsive e-commerce frontend built with **React.js**, **Tailwind CSS**, and **React Router**. This project showcases a clean UI, state management using React Context API, and interaction with a dummy product API.

## 📦 Features

- Responsive and modern UI using **Tailwind CSS**
- Product listing from a public API (`fakestoreapi.com`)
- Hero section, Featured Products, and Footer
- **Mini Cart** component for quick access to cart items
- **Cart state management** with React Context API
- Add to Cart and Remove from Cart functionality
- Sticky header with active route highlighting
- Error handling and loading states for product fetch

---

## 🛠️ Tech Stack

- **React.js**
- **Tailwind CSS**
- **React Router**
- **Context API** (for cart state)
- **Fake Store API** (for demo product data)
